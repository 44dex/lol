# Första gången ⬇

Gå in på länken https://github.com/44dex/lol/archive/refs/heads/main.zip och gå in på appen filer. Hitta mappen (den heter "lol någonting") i neddladningar och extracta den genom att trycka på den med 2 fingrar och tryck extrahera alla.

<img width="449" height="175" alt="Screenshot 2026-11-12 11 28 59" src="https://github.com/user-attachments/assets/1a359318-1d7f-4a3c-97a8-93180662b049" />

Sen ta bort zip filen och gå in i den nya filen som heter lol som är där nu. Sen gå in på mappen och öppna secret.html och så borde det funka.

# Uppdatera ⬇

Gör samma som där uppe och ta bort den gamla lol filen. Om du sätter den nya lol filen som du satte den gamla så kan du använda samma shortcut som du hade innan.
